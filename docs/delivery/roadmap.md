# Delivery roadmap

| Initiative | Target | Exit evidence |
| --- | --- | --- |
| 1. Repository and developer experience | Week 1 | Clone-to-running path, green CI, web/worker/PostgreSQL, one Playwright journey |
| 2. Delivery platform | Weeks 1–2 | Immutable image reaches development; production remains manual; smoke and rollback evidence |
| 3. Hetzner infrastructure | Weeks 2–3 | Reproducible isolated environments and a restored development backup |
| 4. SaaS foundation | Weeks 3–4 | Auth journey, activation events, observable jobs, privacy-safe errors |
| 5. Product experiment framework | Weeks 4–5 | Measurable landing experiment, manual fulfilment, evidence-led decision |
| 6. First vertical slice | Weeks 5–6 | Five external completions, measured effort/accuracy, payment ask, decision |
| 7. Monetisation | Weeks 6–8, after evidence | Idempotent test checkout and entitlements; human-reviewed live readiness |

The detailed initiative, epic, and first-story catalogue is in
`issue-catalogue.md`. `scripts/bootstrap-github.sh` can preview the corresponding
GitHub changes without mutating the repository.
